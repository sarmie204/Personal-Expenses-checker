# Personal Expense Tracker

## About the Project

The Personal Expense Tracker is a simple Python-based application designed to help individuals monitor their daily spending.

I developed this project to explore how programming can solve everyday financial management problems. The application allows users to record expenses, organise transactions and calculate their overall spending.

## Features

- Record daily expenses.
- Categorise spending.
- View transaction history.
- Calculate total expenditure.
- Store records in a CSV file.
- Validate user input.

## Technologies Used

- Python 3
- CSV
- Datetime
- File handling

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run:

   python expense_tracker.py
